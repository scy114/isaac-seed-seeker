Isaac Seed Seeker 使用说明
============================

这是一个面向《以撒的结合：忏悔+》伊甸开局的非官方离线种子筛选器。
程序只在本机运行，不需要 Python、Node.js 或网络连接。


一、开始使用
------------

1. 把 ZIP 完整解压到任意文件夹。
2. 双击 IsaacSeedSeeker.exe。
3. 程序会打开一个黑色窗口，并自动在默认浏览器中打开筛选页面。
4. 使用完毕后，点击网页底部的“关闭本地程序”。

不要直接在压缩包预览窗口里运行 EXE。请先完整解压，否则浏览器或导出功能可能表现异常。


二、填写筛选条件
----------------

页面默认不携带任何道具条件。

- 口袋物：先选择饰品、卡牌、胶囊效果或“没有口袋物”，再按名称或 ID 选择条目。
- 主动/被动：输入中文名、英文名、常用俗称、拼音或数字 ID，然后从推荐列表中选中条目。
- 同一栏中的多个条目是“任意一个即可”（OR）。
- 不同类别之间必须同时满足（AND）。
- “排除”栏中的条目命中后会被过滤掉。
- 血量和属性只填写需要限制的最小值或最大值；留空表示不限。
- 钱、钥匙、炸弹筛选的是伊甸出生时自身携带的资源，不包含道具额外生成的掉落物。
- 若想找黄针开局，可选择某项属性上升、下降或不变，也可填写黄针结算后的面板区间；无需另外把被动 ID 240 填一遍。
- 胶囊按每局种子随机生成的“颜色 → 效果”映射筛选。结果会同时显示效果 ID 和颜色；马胶囊按相同的基础效果匹配，金色胶囊没有单一固定效果。

例子：

- 想找“某个饰品，并且主动是两个候选之一”：在饰品栏选择 1 个条目，在主动栏选择 2 个条目。
- 想找“伤害至少 4.0”：只填写伤害最小值 4.0，最大值留空。
- 想排除某件被动：把它加入“排除被动道具”。
- 想找“黄针让伤害上升、射程不变”：在“实验性疗法（黄针）”区域选择对应方向。


三、扫描范围与结果上限
----------------------

- 默认范围是全部 2^32 - 1 个可搜索种子值。
- “线程”一般保持默认值即可。
- “内存载入上限”控制网页最多保留多少条结果，范围为 1～10,000。
- 命中数超过载入上限时，程序仍会完成全范围扫描并显示真实命中总数，但网页只保留当前排序下最靠前的若干条。
- 点击结果表头可以按血量、钱、钥匙、炸弹、属性、主动/被动品质或总品质升降序排列。
- 若结果已被截断，可以按照当前排序重新扫描，获得精确的全局 Top-K。


四、导出与关闭
--------------

- 扫描结束后，点击“导出当前排序 TXT”保存当前结果。
- 网页依赖正在运行的 IsaacSeedSeeker.exe；关闭黑色窗口后，页面会停止工作。
- 正常退出请优先使用网页底部的“关闭本地程序”。


五、游戏图标与背景
------------------

筛选核心不依赖游戏正在运行，也不要求解包游戏资源。

如果本机已经使用游戏自带的 ResourceExtractor 解包资源，程序会自动定位 Steam 游戏目录，并从本机的 extracted_resources 中读取道具图标和地下室背景。发行包不会复制或附带游戏原始美术资源。

没有解包资源时，筛选仍然可以正常使用，只是部分界面会退回文字或简化背景。


六、常见问题
------------

1. 双击后浏览器没有打开
   查看黑色窗口中的 http://127.0.0.1:... 地址，把完整地址复制到浏览器。不要关闭黑色窗口。

2. 浏览器提示无法访问页面
   本地程序可能已经关闭。重新双击 IsaacSeedSeeker.exe。

3. Windows 显示“已保护你的电脑”
   测试包目前没有商业代码签名。先核对发布页提供的 SHA-256；确认文件来自可信来源后，可在提示中选择“更多信息”查看运行选项。

4. 名称输入后不能开始扫描
   名称搜索必须从推荐列表中选中条目。也可以直接输入数字 ID 后选择对应推荐项。

5. 找不到预期种子
   当前内置 Profile 对应 v1.9.7.17.J460、全解锁、未启用大型内容 Mod。版本、解锁状态或内容 Mod 改动物品池时，结果可能不同。

6. 普通与困难模式是否不同
   当前筛选的是伊甸开局生成。普通/困难不会改变这里使用的开局 RNG 与内置物品池模型。

7. 为什么游戏中的胶囊效果看起来不同
   程序筛选的是本局胶囊池的原始效果。PHD、假 PHD、幸运脚等开局道具，以及低血量下的 Health Down / Bad Trip 转换，可能改变实际服用时解析出的效果。


七、版本与反馈
--------------

当前版本见同目录的 manifest.json；平台为 Windows x64。
游戏结果始终是最终真值。反馈问题时请附上：程序版本、游戏版本、筛选条件、种子以及是否启用了内容 Mod。
