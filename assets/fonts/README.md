# IsaacSans

`Isaacsans-lEpZ.ttf` is IsaacSans by Shrapnel, a fan-made typeface inspired by
the sketchy lettering in *The Binding of Isaac*.

- Source: https://www.fontspace.com/isaacsans-font-f18283
- Retrieved: 2026-08-05
- License: Public Domain

The upstream download includes the same license and source URL in `info.txt`;
that file is preserved here as `LICENSE-IsaacSans.txt`.

# LanaPixel

`LanaPixel.ttf` is LanaPixel 001.003 by eishiya, the CJK pixel font used by
the extracted game resources. The outline TTF is embedded so the offline
WebUI can render Chinese text without installing a system font.

- Source: https://opengameart.org/content/lanapixel-localization-friendly-pixel-font
- Distribution copy: `@fontpkg/lana-pixel@1.3.0`
- Retrieved: 2026-08-05
- MD5: `d355d2d8472d73feb8bc3f25d538878e`
- License: SIL Open Font License 1.1

The copyright notice and full license are preserved as
`LICENSE-LanaPixel.txt`.
